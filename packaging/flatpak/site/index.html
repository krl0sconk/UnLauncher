UnLauncher

A native Unreal Engine launcher for Linux. Version @VERSION@.

Install

You need Flatpak and the Flathub remote, which provides the GNOME runtime:

flatpak remote-add --user --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo
flatpak install --user https://krl0sconk.github.io/UnLauncher/io.github.krl0sconk.UnLauncher.flatpakref

Updates arrive with flatpak update, or from GNOME Software or KDE Discover.

Single file

Each release also carries a .flatpak bundle:

flatpak install --user UnLauncher-@VERSION@.flatpak

Add the repository by hand

flatpak remote-add --user --if-not-exists unlauncher https://krl0sconk.github.io/UnLauncher/unlauncher.flatpakrepo
