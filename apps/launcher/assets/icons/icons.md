# Icons

Lucide (ISC license, `LICENSE-Lucide-ISC.txt`), 24 px grid, 2 px stroke, single ink drawn with `currentColor`: set their color with CSS `color` (or the egui tint), usually `ink` or `ink-muted`, `accent-ink` in the current nav item, a status color in a status badge. Shown at `icon-size` (16 px) in buttons, nav and badges and 24 px in thumbnails and empty states.

| Icon | Means |
| --- | --- |
| `layers` | Library (engines and projects) |
| `store` | Fab |
| `list-checks` | Tasks |
| `settings` | Settings |
| `box` | An engine; a plugin on Fab |
| `package` | An asset pack; a Fab install task |
| `play` | Launch, Resume |
| `pause` | Pause a task |
| `download` | Prebuilt engine, download task, update notice |
| `git-branch` | Engine built from source |
| `hammer` | Source build task |
| `folder-open` | Add folder, Show in folder, import task |
| `folder-search` | Searched folders |
| `hard-drive` | Disk space |
| `plus` | New project, Install engine |
| `refresh-cw` | Refresh |
| `search` | Search fields |
| `ellipsis-vertical` | Card menus |
| `external-link` | Opens a page outside the app (Get more on Fab, GitHub) |
| `log-in` | Sign in |
| `user` | Account |
| `check`, `circle-check` | Done, installed, a completed step |
| `triangle-alert` | Warning: missing engine, low space |
| `x` | Close, cancel, failed |
| `trash-2` | Uninstall, delete |

No emoji anywhere in the app.
